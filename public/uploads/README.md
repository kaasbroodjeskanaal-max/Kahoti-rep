# Uploads Map

Plaats hier je bestanden (afbeeldingen, audio, media, etc.) via de bestandsverkenner van AI Studio.

## Hoe te gebruiken in de Quiz:
Bestanden die je in deze map (`public/uploads/`) zet, zijn direct bereikbaar in de app via het pad:
`/uploads/jouw-bestand.png` (of `.mp3`, `.jpg`, etc.)

Voorbeeld:
- Upload je `kat.png` in deze map?
- Gebruik dan `/uploads/kat.png` als afbeeldings-URL in je quizvraag!
